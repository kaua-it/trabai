04 • Estrutura dos dados

Como os alunos são armazenados?

O projeto utiliza uma lista de listas, funcionando como uma estrutura semelhante a uma matriz.

alunos = [ ["Ana", 8.5, 7.5, 9.0], ["João", 6.0, 5.5, 7.0], ["Maria", 4.0, 5.0, 4.5] ]
Posição Informação
[0] Nome do aluno
[1] Primeira nota
[2] Segunda nota
[3] Terceira nota
05 • Cadastro

Cadastro dos alunos

Para cada aluno, o programa solicita o nome e três notas. Esses dados são armazenados na estrutura de dados.

nome = input("Nome do aluno: ") nota1 = float(input("Nota 1: ")) nota2 = float(input("Nota 2: ")) nota3 = float(input("Nota 3: ")) aluno = [nome, nota1, nota2, nota3] alunos.append(aluno)

06 • Cálculo

Cálculo da média

A média é calculada somando as três notas e dividindo o resultado por três.

media = (nota1 + nota2 + nota3) / 3

Exemplo

8 + 7 + 9

Soma

24 pontos

Média

24 ÷ 3 = 8,0

07 • Condicionais

Definição da situação

Depois de calcular a média, estruturas condicionais determinam a situação do aluno.

if media >= 7: situacao = "APROVADO" elif media >= 5: situacao = "RECUPERAÇÃO" else: situacao = "REPROVADO"
≥ 7 → APROVADO 5 até 6,9 → RECUPERAÇÃO < 5 → REPROVADO
